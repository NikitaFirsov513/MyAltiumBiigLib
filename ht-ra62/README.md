## Как использовать в Altium

1. Сохранить обе библиотеки рядом; они уже находятся в `altium/`.
2. Через File → Open открыть SchLib и PcbLib. В SCH Library выбрать HT-RA62; в PCB Library найти одноимённое посадочное место.
3. Добавить обе библиотеки в проект через Add Existing to Project либо подключить через File-based Libraries Preferences панели Components. Названия пунктов зависят от версии Altium.
4. Проверить модель footprint HT-RA62 и доступность её PcbLib. При необходимости явно указать файл модели.
5. Перед выпуском платы сверить нумерацию, геометрию, слои, маску/пасту, высоту и размещение антенны по образцу.

Это обычные файловые библиотеки; поиск только в Manufacturer Part Search может не показать компонент. Не подменять footprint модулем HT-RA62A или другим изделием на SX1262 только по названию радиочипа.

[Altium: schematic libraries](https://www.altium.com/documentation/altium-designer/components-libraries/file-based-libraries/schematic), [Altium: file-based library search](https://www.altium.com/documentation/altium-designer/schematic/components-file-based-database-libraries).

## Почему рассматриваем

Нам нужен MCU GD32 с независимым SPI-радио для собственной сети, сна и управляемой пересылки. Готовый радиомодуль уменьшает объём ВЧ-разводки по сравнению с отдельным SX1262. Его преимущество перед Wio в нашем обсуждении — найденные бюджетные предложения, а не уникальные радиовозможности. [Официальный магазин Heltec](https://heltec.org/project/ht-ra62/) показывает $3,90 без доставки: экономия относительно Wio сама по себе небольшая. Если реальная закупка не укладывается в 300–500 ₽, выбор следует пересмотреть.

Это радио, а не UART-модем с готовой mesh-прошивкой. Пакеты, маршрутизацию, повторы, сон и хранение данных реализует GD32. [Драйвер Semtech на C](https://github.com/Lora-net/sx126x_driver) предоставляет интерфейс к радиочипу; HAL для SPI/reset/wakeup реализуется под GD32. Он не создаёт нашу сеть автоматически.

## Основные данные и подключение

HF: 863–928 МГц; для предполагаемого 868-МГц узла заказывать соответствующее исполнение. SX1262, SPI, модульная мощность 21±1 dBm. Питание 2,7–3,5 В, типично 3,3 В; источник ≥150 мА. Это требование источника, не постоянный ток. Плата 16×17 мм; 0,8 мм — толщина PCB, не высота собранного модуля. Диапазон чипа 150–960 МГц нельзя переносить на HF-согласование модуля.

| Pin | Сигнал | Назначение |
|---:|---|---|
| 1 | ANT | ВЧ-порт |
| 2, 9, 16 | GND | Земля |
| 3 | 3V3 | Питание |
| 4 | RST | Сброс от MCU |
| 5 | TXEN | ВЧ-коммутатор; смотреть внутреннюю схему |
| 6 | DIO1 | IRQ к MCU |
| 7 | DIO2 | Управление ВЧ-коммутатором в опубликованной схеме |
| 8 | DIO3 | Питание генератора в опубликованной схеме |
| 10 | BUSY | Готовность радиочипа, вход MCU |
| 11 | RXEN | ВЧ-коммутатор; смотреть внутреннюю схему |
| 12 | SCK | SPI clock |
| 13 | MISO | SPI к MCU |
| 14 | MOSI | SPI от MCU |
| 15 | NSS | SPI chip select |

Номера относятся к модулю, а не к выводам микросхемы SX1262. DIO2/DIO3 нельзя бездумно использовать как свободные GPIO или замыкать на питание. Напряжение и задержку TCXO, RF-switch и установленную обвязку проверить для закупаемой ревизии. SPI-ответ при неверном управлении ВЧ-коммутатором ещё не доказывает работоспособность радиотракта.

## Ограничения документации и следующие проверки

- В Rev.1.1 указан шаг 1,27 мм, а механический рисунок содержит обозначение `2*8`. По одной этой таблице посадочное место не строить; официальную PcbLib проверить по геометрии и образцу.
- Общая таблица даёт −134 dBm, таблица SF12/BW125 — −139 dBm. Не считать вторую цифру гарантированной характеристикой готового узла.
- Отдельных гарантированных токов всего модуля в RX/TX/sleep этот datasheet не содержит. Для SX1262 Semtech приводит ориентиры 4,6 мА RX и 118 мА TX при +22 dBm; это не измерение HT-RA62. [Первичный источник Semtech](https://www.semtech.com/amazon-sidewalk-lora).
- Наличие TCXO/ВЧ-коммутатора и параметры их управления проверяются по реальному модулю. В опубликованной схеме генератор X1 питается через DIO3, коммутатор связан с DIO2, R4 отмечен NC. Это не требует автоматически назначать отдельные MCU GPIO всем TXEN/RXEN/DIO.
- IPEX и ANT — варианты подключения одного ВЧ-тракта; не подключать две антенны параллельно. Для вынесенного разъёма нужна согласованная 50-Ом линия по стеку PCB.
- LoRaWAN и mesh — программные протоколы поверх радиоканала; модуль не заменяет многоканальный концентратор и не принимает все радиопрофили одновременно.

До финальной PCB: получить два HF-образца, сверить библиотеку и осциллятор, проверить SF12/BW125, сон/RX/TX и работу при низком заряде. Схема включения под GD32 и измеренный энергобюджет ещё не выпущены.
